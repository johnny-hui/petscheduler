Pet Scheduling App

This project is a full-stack pet-sitting scheduling and booking platform.

Status: In Active Development (Back-end Only)

Overview

PetScheduler is a full-stack web application designed to connect pet owners with independent pet sitters and pet-sitting businesses.

The app aims to simplify pet care scheduling by allowing pet owners to manage their pets, discover available sitters, and request bookings based on sitter availability.

Pet sitters and businesses can manage their availability, review incoming booking requests, and maintain their profiles.

The project is being developed with a focus on RESTful API design, backend architecture, security authentication and authorization, relational database design, business logic validation, and automated testing.

Development Status and Roadmap

This project is currently being developed with the back-end being emphasized first. Once the back-end is completed and testing has been completed, front-end development will be started. Following this, some form of AI will be incorporated into this application such as LLM API integration and AI assistance.
